# Frame scenario assets

These three original scenario images were generated with `gpt-image-2` on 2026-08-20 for the V5 landing page:

- `idol-support-frame.webp`
- `illustrator-collaboration-frame.webp`
- `coffee-shop-brand-frame.webp`

They contain fictional concepts only and intentionally avoid real people, existing brands, logos, and readable promotional copy. The generation prompts are archived in `output/imagegen/frame-scenes/prompts.jsonl`.
