# Operating scenario assets

These original scenario images were generated with `gpt-image-2` on 2026-08-20 for the landing-page operating-context section:

- `brand-hospitality.webp`
- `brand-hospitality-v2.webp` — recomposed window-seat keepsake experience
- `creator-paid-service.webp`

They use the project product photography as a machine-design reference. All shops, people, printed portraits, frame artwork, payment equipment, and commercial contexts are fictional. No real customer, brand, price, or payment service is represented. The final prompts are archived under `output/imagegen/operating-scenarios/prompts/`.
